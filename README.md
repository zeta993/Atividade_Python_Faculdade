## 📚 Atividades

### 📝 Atividade 01 — Sistema de Notas

Sistema desenvolvido para cadastrar notas de um aluno, calcular sua média e informar sua situação de aprovação.

A atividade possui duas versões:

**Versão 01 — Funções**
- Listas
- Funções
- Estruturas condicionais
- Estruturas de repetição
- Tratamento de exceções
- Menu interativo
- Cálculo de média

**Versão 02 — POO**

Após concluir a atividade original, o sistema foi refatorado voluntariamente utilizando **Programação Orientada a Objetos**.

Nesta versão foram utilizados:
- Classes e objetos
- Métodos
- Dicionários
- Validação de dados
- Consulta por matrícula
- Cálculo de média
- Menu interativo

📁 `atividade_01_sistema_de_notas/`

### 📊 Atividade 03 — Análise de Vendas

Aplicação desenvolvida para armazenar, processar e visualizar dados de vendas.

Os registros são armazenados em um banco de dados **SQLite** e posteriormente carregados em um **DataFrame Pandas** para análise.

O sistema permite:
- Analisar vendas por categoria
- Analisar vendas por mês
- Calcular o valor total vendido
- Calcular o ticket médio
- Consultar a quantidade de vendas
- Visualizar a participação de cada categoria

Visualizações utilizadas:
- Gráfico de barras
- Gráfico de linhas
- Gráfico de pizza

Tecnologias:
- Python
- SQLite
- Pandas
- Matplotlib
- Seaborn

📁 `atividade_03_analise_de_vendas/`
